<h1 align="left">⛏️ Novatime</h1>

###

<p align="left">Лендинг-сайт для игрового сервера NOVAtime, созданный для привлечения игроков и презентации ключевых особенностей проекта. Быстрая загрузка, современный дизайн и адаптивная верстка — всё, чтобы произвести впечатление.</p>

###

<h2 align="left">🧑‍💻 Технологии сайта</h2>

###

• 	Vite — мгновенная сборка и dev-сервер

• 	HTML5 + CSS3 — адаптивная и семантическая верстка

• 	JavaScript — интерактивные элементы

• 	GitHub Pages — хостинг лендинга

###
